Telegram-бот для отправки анонимных валентинок с монетизацией аудитории.
Каждый пользователь получает персональную ссылку, по которой ему можно прислать
анонимное сообщение. Получатель может ответить отправителю анонимно или платно
узнать, кто прислал валентинку, — оплата проходит через Telegram Stars.

> 🤖 **Живой пример бота:** [@ToyotaStars_bot](https://t.me/ToyotaStars_bot)

---

## Что делает бот

- выдаёт каждому пользователю персональную deep-link ссылку для приёма валентинок;
- доставляет анонимные сообщения получателю с кнопками «Ответить» и «Узнать отправителя»;
- позволяет получателю анонимно ответить отправителю в обе стороны;
- продаёт раскрытие отправителя за Telegram Stars (цена настраивается в админ-панели);
- закрывает доступ к боту обязательной подпиской на каналы-спонсоры и интеграцией с Flyer;
- ведёт учёт реферальных и рекламных (UTM) ссылок со статистикой переходов;
- умеет делать массовые рассылки с медиа, кнопками и оплатой через Telegram Stars прямо в рассылке;
- даёт администраторам статистику, управление ценами, спонсорами и выгрузку базы.

## Как это работает

Бот построен на **aiogram 3** (long polling) с конечным автоматом (FSM) для
пошаговых сценариев и middleware-конвейером для сессий БД, профиля пользователя
и проверки подписки.

Основной пользовательский поток:

1. Пользователь отправляет `/start` и получает приветствие, меню и свою личную
   ссылку вида `https://t.me/<bot>?start=<payload>`. Payload — это зашифрованный
   ID пользователя (`aiogram` deep linking).
2. Когда кто-то открывает чужую ссылку, бот переводит его в состояние «напиши
   валентинку» и ждёт текст.
3. Текст сохраняется как запись `ValentineMessage`, после чего доставляется
   получателю отдельным сообщением с inline-кнопками: ответить анонимно или
   купить раскрытие отправителя за Stars.
4. Получатель либо отвечает (тот же FSM-сценарий в обратную сторону), либо
   оплачивает раскрытие. Оплата проверяется в `pre_checkout_query` и
   подтверждается в обработчике `successful_payment`, после чего имя отправителя
   показывается только получателю.
5. Перед использованием middleware подписки проверяет, выполнил ли пользователь
   обязательную подписку на спонсоров/Flyer; невыполненные пункты показываются
   списком, а доступ выдаётся после прохождения проверки.

Данные хранятся через **SQLAlchemy 2 (async)** в SQLite (`aiosqlite`). Модели
лежат в `app/database/models` — пользователи, валентинки, спонсоры, рефералы,
рекламные ссылки, шаблоны сообщений, счета и настройки цен.

## Админ-панель

Панель открывается прямо в чате с ботом и доступна только администраторам
(ID из `BOT_ADMINS` в `.env`, а также назначенным админам). Меню инлайновое —
каждая кнопка ведёт в свой раздел, везде есть кнопка «Назад».

| Раздел | Команда | Что делает |
|---|---|---|
| 📊 Статистика | `/stats` | Всего пользователей, число админов, пользователей с именем, приход за сегодня / неделю / месяц. |
| 📨 Рассылка | `/mailing` | Массовая рассылка по всем пользователям. Поддерживает текст, фото, видео, GIF, документы, аудио, голосовые, стикеры и видеокружки; предпросмотр, подтверждение и фоновую отправку с кнопкой остановки. Кнопки могут быть обычными ссылками или **кнопкой оплаты в Telegram Stars** — формат `Текст - stars:25` или `Текст - xtr:25`, счёт выставляется прямо из рассылки. |
| 📢 Спонсоры | `/sponsors` | Обязательная подписка: добавление каналов и ботов, включение/выключение Flyer и собственных каналов, лимит заданий Flyer, лимиты переходов по каждому спонсору, активация/деактивация и удаление. |
| 📥 Выгрузка | `/dump` | Экспорт всех пользователей в CSV (id, username, имя, фамилия, дата захода, признак админа). |
| 🔗 UTC ссылки | `/utc` | Рекламные и реферальные ссылки с бюджетом и подробной статистикой: переходы, уникальные, активные, подписавшиеся, приход по периодам и стоимость за переход / пользователя / подписчика. |
| 👤 Админы | `/admins` | Корневые админы из `.env` (👑) и назначенные (🛡). Выдача и снятие прав по ID — доступно только корневым админам. |
| 💬 Приветка | `/greeting` | Редактирование приветственного сообщения (любой тип контента), предпросмотр и сброс к стандартному. |
| 🏠 Меню старта | `/startmenu` | Редактирование стартового меню, предпросмотр и сброс к стандартному. |
| ⭐ Кто отправил | `/revealprice` | Настройка цены раскрытия отправителя валентинки в Telegram Stars. |

## Структура проекта

```
.
├── main.py                  # точка входа: инициализация бота и диспетчера
├── admin_source.py          # сборка админ-роутера и middleware, миграция старой БД

├── States/                  # состояния FSM
├── bot_media/               # медиа бота (картинки уведомлений и приветствия)
└── app/
    ├── database/            # движок, фабрика сессий и модели SQLAlchemy
    ├── filters/             # фильтры (админ, бан, VIP, подписка)
    ├── handlers/admin/      # админ-панель: статистика, рассылки, цены, спонсоры
    ├── middlewares/         # сессия БД, профиль пользователя, проверка подписки
    ├── templates/           # тексты и клавиатуры (user/admin)
    └── utils/               # конфиг, оплаты, подписка, рассылки, графики и т.д.
```

## Установка и запуск

```bash
git clone https://github.com/StarList682/Telegram_Valentinkibot.git
cd Telegram_Valentinkibot

python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

pip install -r requirements.txt

cp .env.example .env               # затем заполните .env своими значениями
python main.py
```

Перед запуском в файле `.env` нужно указать минимум токен бота (`BOT_TOKEN`) и
ID администраторов (`BOT_ADMINS`). База данных SQLite создаётся автоматически при
первом старте.

## Конфигурация (`.env`)

| Переменная | Назначение | Пример / по умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather | — (обязательно) |
| `BOT_ADMINS` | Список ID администраторов | `[123456789]` |
| `BOT_MODERS` | Список ID модераторов | `[]` |
| `BOT_TIMEZONE` | Часовой пояс для статистики | `Asia/Yerevan` |
| `BOT_USE_REDIS` | Использовать Redis для FSM | `False` |
| `DB_URL` | Строка подключения к БД | `sqlite+aiosqlite:///anonchat_admin.sqlite3` |
| `FLYER_KEY` | Ключ Flyer (обязательная подписка) | пусто = выключено |
| `FLYER_BASE_URL` | Базовый URL Flyer API | `https://api.flyerservice.io` |
| `PAYMENTS_ENABLED` | Включить внешние платёжные провайдеры | `False` |

Раскрытие отправителя работает на Telegram Stars и не требует платёжного токена.
Дополнительные провайдеры (Crypto Pay, Platega, PayOK) включаются и настраиваются
через переменные `PAYMENTS_*` — полный список параметров см. в `app/utils/config.py`.

---

## Подключение новых способов оплаты

Платёжная логика вынесена в `app/utils/payments.py`. Чтобы добавить нового
провайдера, реализуйте создание счёта и проверку платежа на базе общего интерфейса
`BasePayment`, а затем подключите провайдер к нужному пользовательскому сценарию.
